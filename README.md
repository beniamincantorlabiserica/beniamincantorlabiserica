## Featured Projects

### Scentinel — Health-tech IoT platform
*FastAPI · PostgreSQL · SvelteKit · Cloudflare · Docker · Caddy*

Full platform behind a sensor device that detects incontinence in care homes. **In production with 4M+ readings.**
- Device ingestion API, care-staff web app, OTA firmware updates with rollback
- PostgreSQL scaled to 86k rows/device/day with partitioning and aggregates
- Cloudflare Zero Trust, row-level security, nightly tested backups, CI/CD

### ArbejdsBro — B2B workforce-sharing marketplace
*SvelteKit · TypeScript · Supabase · Tailwind · Docker · GitHub Actions*

Verified Danish companies lend and borrow idle workers. **Spec to production in under two weeks (~17k lines).**
- Matching engine scoring offers 0–100 on skills, certificates, dates, distance and quantity
- Concurrency-safe bookings, role-based access, invite-only onboarding, GDPR retention
- No direct DB access from the browser, security headers, rate limiting

### Hamsø Customer Portal
*SvelteKit · PocketBase · Tailwind*

Client dashboard for orders, cases, file sharing and real-time messaging, plus admin area and marketing site. Built solo, live in production.

### HapticStudio
*SvelteKit · Web Audio · Docker*

Web and macOS tool for designing haptic patterns. Scrum Master in a team of 3; built the audio engine and timeline editor and set up Docker with automatic VPS deploys.
